# 🇱🇧 منصة الطوارئ - لبنان

Emergency Response Platform for Lebanon

## About

A volunteer-run platform to help people affected by conflict in Lebanon find shelter, coordinate aid, and access emergency services.

## Features

- 🏠 Available Shelters
- 🆘 Shelter Requests
- 📦 Aid Coordination
- 🚨 Emergency Contacts
- 🚩 Community Reporting
- 📱 Mobile Responsive
- 🔒 Admin Moderation

## Disclaimer

This platform is independent and not affiliated with any government. All information is user-generated. Please verify all details before taking action.
